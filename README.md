### Description

A simple portfolio template for developer/designers built with React. 

### Features

- Fully Responsive
- Multi-Page Layout
- Contact Form With EmailJs
- React-Bootstrap
- Edit Content From One Place

### Social Media Preview

This portfolio includes comprehensive Open Graph and Twitter Card meta tags for rich social media previews. 

**After making changes:**
1. Deploy with: `pnpm run deploy`
2. Go to [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/)
3. Enter: `https://thanhng224.github.io/react-portfolio/`
4. Click "Scrape Again" 2-3 times to refresh the cache
5. Test sharing on Facebook/Messenger to verify the preview
